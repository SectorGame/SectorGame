### ⏳ [T-Minus Countdown: Reverse-Engineering My AWS Certification Prep](https://app.joinhandshake.com/ai-showcase/projects/3766478?ref=profile)

[![T-Minus Countdown AWS certification study plan](https://joinhandshake-production.imgix.net/app/public/assets/projects/003/766/478/cover/original/geminigeneratedimage52fud752fud752fu.jfif?ixlib=rb-4.1.1&v=1794411137&s=f8a57f4752ffbdd4cf5e28c04de32c80)](https://app.joinhandshake.com/ai-showcase/projects/3766478?ref=profile)

**AI-powered study planning · AWS · Gemini · Active recall**

Designed a focused **14-day AWS certification prep sprint** by using Gemini to work backward from the exam blueprint. The plan turns passive studying into five active-recall milestones, from reviewing **IAM, VPC, and S3** at T-14 to completing a timed **65-question mock exam** at T-3.

**Key takeaway:** Combined backward milestone planning with spatial image prompting to create a practical countdown checklist that fits beneath a phone's lock-screen clock.

**Next.js · Supabase Realtime · Vercel · Multiplayer game development**

Built a browser-based memory game featuring **single-player and multiplayer modes**, **20 progressively harder levels**, competitive scoring, and a **Top 50 leaderboard**.

The core engineering challenge was coordinating synchronized multiplayer rounds, timers, scores, reconnects, and player state in real time, using server-side game logic and Supabase Realtime.
